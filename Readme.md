# Python Programming

A personal programming journal: Python coursework from the IITM BSc Data Science & Applications program, plus ongoing LeetCode practice for data structures and algorithms.

The repo is organised by topic, one folder per track, so new areas can be added alongside the existing ones.

## Repository Structure

```
Python-Programming/
├── Assignments/     IITM BSc Python assignments (24 files)
├── LeetCode/        LeetCode solutions, one folder per problem (99 problems)
└── Readme.md
```

| Folder | What's inside |
| ------ | ------------- |
| [`Assignments/`](Assignments) | Graded-style Python exercises, from conditionals and loops through OOP and NumPy |
| [`LeetCode/`](LeetCode) | Solutions synced from LeetCode with [LeetHub v2](https://github.com/arunbhardwaj/LeetHub-2.0) |

## Assignments

Solutions to Python programming assignments from the IITM BSc Data Science & Applications program. Each file starts with a header naming the topic, followed by the original question as a comment and then the solution.

| Area | Files |
| ---- | ----- |
| Conditionals & loops | `If_else.py`, `For_loop.py`, `While_loop.py`, `Nested_loop.py`, `Loops_extra.py` |
| Functions | `Functions.py`, `higher_order_functions.py`, `map_filter_zip.py` |
| Data structures | `List_functions.py`, `list_set_operations.py`, `dictionary.py`, `Dictionary_advanced.py`, `Iterables.py`, `slicing.py` |
| Comprehensions | `List_comprehensions.py` |
| Strings & arithmetic | `string_manipulation_class.py`, `artihmetic.py`, `swap_operations.py` |
| 2D problems | `Matrix.py` |
| Object-oriented programming | `classes.py`, `inheritance.py`, `time_conversion_class.py`, `grocery_list.py` |
| NumPy | `numpy_filtering.py` |

Run any file directly:

```bash
python Assignments/classes.py
```

Only `numpy_filtering.py` needs an extra package (`pip install numpy`).

## LeetCode

Solutions to LeetCode problems solved as part of ongoing DSA practice, written in Python.

Each problem has its own folder named `<number>-<problem-slug>`, for example `0001-two-sum`, containing:

- `<number>-<problem-slug>.py` is the solution.
- `README.md` is the problem statement with its difficulty and a link to LeetCode.

Topics practised so far include arrays and strings, two pointers and sliding window, hashing, binary search, sorting, greedy, math and number theory, stacks, and recursion.

[`LeetCode/README.md`](LeetCode/README.md) is generated by LeetHub and groups problems by topic.

## Adding a New Folder

Git doesn't track empty folders, so add at least one file to a new folder before committing.

```bash
git pull
mkdir Projects
echo "# Projects" > Projects/README.md
git add Projects
git commit -m "Add Projects folder"
git push
```

Then add a row for it in the structure table above.

## Notes

- LeetHub pushes new submissions to the repo root by default. If new problem folders appear there, move them into `LeetCode/` with `git mv`, or change the target folder in the LeetHub extension settings.
